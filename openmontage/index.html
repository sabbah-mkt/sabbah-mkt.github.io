حوّل Claude إلى استوديو إنتاج كامل

OpenMontage أداة مجانية مفتوحة المصدر على GitHub. تفتحها داخل Claude Code وتكتب فكرتك بجملة واحدة، فيعمل الذكاء الاصطناعي كفريق إنتاج: يبحث، ويكتب السكربت، ويجهّز الصور واللقطات والصوت، ثم يركّب فيديو نهائياً. في هذه الصفحة كل خطوة ومعها رابطها الرسمي.

تحميل الدليل (PDF)صفحة الأداة على GitHub

فريق الإنتاج داخل الأداة

الباحث research

يبحث عن موضوعك على الإنترنت ويجمع المصادر قبل الكتابة.

الكاتب script

يكتب السكربت مقسّماً إلى مشاهد، ويعرضه عليك للموافقة.

المنتج scene_plan · assets

يخطّط المشاهد ويولّد الصور أو يجلب لقطات حقيقية (B-roll) من مصادر مجانية.

فني الصوت والمونتاج

يضيف التعليق الصوتي والموسيقى والترجمة، ثم يُخرج الفيديو النهائي.

ماذا تحتاج قبل البدء؟

Claude Code

المساعد الذي سيشغّل الأداة. تعمل أيضاً مع Cursor وCodex وCopilot وWindsurf.

دليل Claude Code الرسمي

Python 3.10 أو أحدث

عند التثبيت على ويندوز فعّل خيار Add to PATH.

تحميل Python

Node.js

لمحرّك تركيب الفيديو. نزّل نسخة LTS الحالية.

تحميل Node.js

FFmpeg وGit

FFmpeg لترميز الفيديو والصوت، وGit لتنزيل الأداة.

تحميل FFmpegتحميل Git

التثبيت في 3 خطوات

  1. نزّل الأداة. افتح الطرفية (Terminal) واكتب: 
    git clone https://github.com/OpenMontageInc/OpenMontage.git
cd OpenMontage
    قسم Quick Start
  2. جهّز الأداة. على ماك ولينكس اكتب make setup. وعلى ويندوز لا يوجد make، فانسخ أمر PowerShell الجاهز من قسم Quick Start، وهو يبدأ بـ py -3 -m venv .venv. وإن ظهر خطأ عند npm install على ويندوز فاستخدم npx --yes npm install.
    أوامر التثبيت الرسمية
  3. افتح المجلد في Claude Code واطلب فيديو. من داخل مجلد OpenMontage شغّل claude ثم اكتب فكرتك، مثلاً: 
    Make a 45-second animated explainer about why the sky is blue
بدون أي مفاتيح مدفوعة تعمل الأداة فعلاً: تعليق صوتي مجاني (Piper)، ولقطات حقيقية مفتوحة من Archive.org وNASA وWikimedia Commons، ومونتاج بـ FFmpeg.
