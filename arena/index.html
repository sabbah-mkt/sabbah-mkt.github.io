خلّي 100 نسخة من Claude يتحاربوا… والأقوى بيضل

Arena أداة مجانية (skill) لـ Claude Code. بتعطي نفس المهمة لنسخ كثيرة من Claude، كل نسخة بتفكر بطريقة مختلفة. بعدين بيهاجموا حلول بعض، وبيدافعوا وبيصلّحوا، وحَكَم بيعطي علامة، والخسران بيطلع، لحتى يضل حل واحد.

صفحة الأداة على GitHubطريقة التنزيل

كيف بتشتغل

1. نفس المهمة لكل النسخ

كل نسخة بتاخد «كرت» مختلف: طريقة تفكير، وطريقة شغل، واستراتيجية. في 2,160 كرت مختلف.

2. هجوم ودفاع

بيتقسموا أزواج. كل واحد بيهاجم حل التاني (لحد 7 ملاحظات: FATAL أو MAJOR أو MINOR)، وبعدين بيدافع عن حله وبيصلّحه.

3. الحَكَم

حَكَم منفصل بيعطي علامة من 100: الصحة 30، الاكتمال 25، الصمود أمام الانتقادات 20، الدقة 15، الوضوح 10. الخسران بيطلع.

الأداة ما بتعدّل ملفاتك. كل شغل النسخ بينكتب بمجلد اسمه .arena، والحل الفائز بيرجعلك وانت بتقرر شو تعمل فيه.

طريقة التنزيل

  1. بتحتاج Claude Code و Python.
    تنزيل Claude Codeتنزيل Python
  2. أسهل طريقة: الصق هاد بـ Claude Code: 
    https://github.com/Jakeschincariol/arena-skill

Install this skill, then confirm /arena works.
  3. أو بإيدك من الـ Terminal: 
    git clone https://github.com/Jakeschincariol/arena-skill.git
cp -r arena-skill/skills/arena ~/.claude/skills/

طريقة الاستعمال

لما يعطيك Claude جواب ما عجبك، اكتب:

/arena --quick

هيك بياخد آخر طلب إلك كمهمة، والجواب اللي ما عجبك كجواب لازم ينغلب. أو اكتب المهمة مباشرة:

/arena --quick اكتبلي هوك لريل عن ...

⚠️ الكلفة

الأداة ببلاش، بس كل نسخة بتصرف من حدود استخدامك لـ Claude:

100 نسخة (الافتراضي)

7 جولات، 595 عملية. خليها للإشيات المهمة جداً.

16 نسخة: --quick

4 جولات، 91 عملية. هاي الأنسب للاستعمال اليومي.

نصيحة: اكتب المهمة واضحة وفيها كل الشروط. النسخ ما بتشوف محادثتك، بتشوف بس ملف المهمة، فإذا شرط ما انكتب، كلهم رح يفوّتوه.
