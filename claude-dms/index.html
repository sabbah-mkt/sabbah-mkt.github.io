أرسل رسائل الكومنتات بدون اشتراك… عبر Claude

عندما يكتب المتابع كلمة معيّنة تحت مقطعك تصله رسالة خاصة فيها الرابط. الأدوات الجاهزة لها حصص مجانية محدودة، وعندما تنتهي تتوقف الأتمتة. هنا طريقتان لإرسال الرسائل عبر الواجهة الرسمية لإنستغرام دون اشتراك.

القواعد الرسمية قبل أن تبدأ

7 أيام لكل كومنت

يمكن الرد على الكومنت برسالة خاصة خلال 7 أيام فقط من كتابته، ورسالة واحدة لكل كومنت.

توثيق Meta الرسمي

حساب احترافي

Business أو Creator. الحساب الشخصي لا يدعم هذه الواجهة، والتحويل مجاني.

تحويل الحساب

حدّ ساعي

تذكر المصادر نحو 750 رداً خاصاً في الساعة لكل حساب، فأضف فاصلاً بين الرسائل ولا تكرّر الإرسال.

تنبيه: أنت المسؤول عن الالتزام بسياسات إنستغرام. أرسل فقط لمن كتب الكلمة بنفسه.

الطريقة الأولى: عبر Claude مباشرة

  1. أضف Composio إلى Claude. من Connectors ← Add custom connector وسمِّه Composio والصق الرابط: 
    https://connect.composio.dev/mcp
    دليل Composio الرسميالأسعار (خطة مجانية)
  2. اربط حساب إنستغرام. اطلب من Claude: «اربط حساب إنستغرام» ثم وافق من الرابط الذي يعطيك إياه.
  3. اطلب الإرسال. اطلب أولاً قائمة بمن سيستلم دون إرسال، راجعها، ثم قل له أرسل: 
    Find everyone who commented "montage" on my latest reel and has no DM thread with me. Send each a private reply with this link: https://your-site.com. Wait 3 seconds between messages. Never message the same person twice.
ملاحظة: هذه الطريقة تستهلك من حدود استخدام Claude في كل مرة. للأتمتة المتكرّرة استخدم الطريقة الثانية.

الطريقة الثانية: سكربت على جهازك بدون Claude

يتصل السكربت بإنستغرام عبر Composio مباشرة فلا يستهلك من حدود Claude، ويعمل كل ساعة. وهو مكتوب بلغة Python دون مكتبات إضافية، ويمكنك قراءته قبل التشغيل.

dm_sweep_local.py

السكربت الرئيسي.

تحميل

dm_campaigns.example.json

نموذج الحملة: الكلمة، والمقطع، والرسالة.

تحميل

env.example.txt

نموذج المفتاح واسم الحساب. بعد التحميل غيّر اسمه إلى .env.

تحميل
  1. المفتاح. من لوحة Composio: Settings ← Sessions & API Key. أنشئ ملف .env بجانب السكربت وضع فيه المفتاح واسم حسابك. لا تشاركه مع أحد، فهو يفتح كل التطبيقات التي ربطتها.
    لوحة Composio
  2. الحملة. انسخ dm_campaigns.example.json إلى dm_campaigns.json وغيّر الكلمة ورقم المقطع ونص الرسالة والرابط.
  3. جرّب بدون إرسال. 
    python dm_sweep_local.py --check
python dm_sweep_local.py --dry
    الأول يفحص الاتصال، والثاني يعرض من سيستلم الرسالة دون إرسال. راجع القائمة جيداً.
    تحميل Python
  4. شغّله فعلياً. 
    python dm_sweep_local.py
  5. جدوِله كل ساعة. على ويندوز (غيّر المسارين): 
    schtasks /Create /SC HOURLY /TN "ig-dm-sweep" /TR "\"C:\Path\to\pythonw.exe\" \"C:\Path\to\dm_sweep_local.py\"" /F
    وعلى ماك أو لينكس ضع هذا السطر في crontab -e: 
    0 * * * * /usr/bin/python3 /path/to/dm_sweep_local.py
    شرح Task Scheduler
